# Shivansh Sahu - Personal Portfolio

## About

This is my personal portfolio website. It introduces me, shows my skills and projects, includes my education, and provides a way to contact me.

I chose a simple dark design with minimal colors and clear sections.

## Technologies Used

- HTML
- CSS

No JavaScript or CSS frameworks are used in this portfolio.

## Features

- Navigation links to different sections
- About, Skills, Projects, Education, and Contact sections
- Flexbox for the navigation and project layout
- CSS Grid for the skills layout
- Responsive layout using media queries
- Hover transitions on links, skills, and projects
- A fade-in animation on the hero section

## How to Run

1. Keep `html.html` and `css.css` in the same folder.
2. Open `html.html` in a web browser.
3. You can also open the folder in VS Code and use Live Server.
